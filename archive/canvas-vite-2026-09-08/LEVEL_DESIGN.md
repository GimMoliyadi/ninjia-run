# 关卡设计优化说明

## 优化内容

### 1. 地刺宽度与间距
- **地刺宽度**：从 18px 加宽到 24px
  - 更醒目，玩家更容易看清
  - 判定更宽容，不会因为差几个像素就判死

- **单/双地刺间距**：200px 安全间距
  - 基础速度（360 px/s）下单跳能稳定跨越
  - 二段跳绝对能跳过，留有余量
  
- **地刺阵（3-4连跳）间距**：340px（200 + 140）
  - 每根之间有足够反应时间
  - 落地后不会立刻撞上下一根
  - 带引导弧线，提示玩家节奏跳跃

### 2. 反应时间优化
- **基础安全间距**：从 `0.9倍` 提升到 `1.15倍`
  - 高速时不会太紧逼
  - 障碍之间多留 50px+ 缓冲空间

- **滚石预警距离**：从 `120px` 加长到 `150px`，反应时间从 `1.0倍` 提升到 `1.4倍`
  - 给玩家更多时间识别并起跳

- **危险事件后额外间距**：从 60px 提升到 120px
  - 每个危险障碍后有明显的喘息段
  - 不会连续紧逼

### 3. 配置文件调整（spawn-config.js）
- **事件间距**：
  - `gapMin`: 30 → 80px（最小间距更宽松）
  - `gapMax`: 220 → 280px（最大间距拉开）
  - `dangerGapBonus`: 60 → 120px（危险后余地翻倍）

### 4. 视觉引导
- **跳跃障碍**：添加金币弧线引导
  - 单地刺、双地刺、地刺阵、石柱、剑忍都带弧线
  - 提前 20-30px 起跳，弧线覆盖整个障碍段
  
- **滑铲障碍**：前置低空金币带
  - 垂板、墨墙前 40px 放一排低空金币
  - 视觉暗示"这里要滑铲"

## 设计原则

1. **保证能力边界**
   - 单跳距离（基础速度）：≈ 255px
   - 二段跳总距离（基础速度）：≈ 488px
   - 障碍间距 ≥ 单跳距离 + 反应时间 + 余量

2. **递进教学**
   - 单根 → 双根 → 地刺阵，难度逐步提升
   - 每个阶段都有足够反应时间
   - 视觉引导（金币弧线）降低学习成本

3. **节奏控制**
   - 危险 → 奖励严格交替
   - 危险后必有 120px 额外喘息
   - 速度越快，自动间距越大

4. **可配置性**
   - 所有数值都在 spawn-config.js 可调
   - 想更难 → 调小 gapMax
   - 想更轻松 → 调大 gapMin 和 dangerGapBonus
