# 飞镖重新设计 · 交接文档

> 交接对象：下一位处理 ninja-run 的对话/开发者。
> 本次改动聚焦一张图一件事：**飞镖潮的高低轨语义 + 节奏宽松 + 波规模收敛**。
> 一句话概括：飞镖变高变醒目、高低轨"必须跳 / 必须滑铲"由盒体几何硬保证、每波 3-5 枚成簇、枚间距放宽到 0.55-0.70s。

## 1. 常量改动（src/constants.js L67-84）

| 常量 | 旧 | 新 | 几何 / 语义 |
|---|---|---|---|
| `DART_H` | 26 | **36** | 碰撞盒更高，配合刃尖视觉加大 → 更醒目 |
| `DART_LOW_LIFT` | 26 | **50** | 低轨盒 [412,448]，站立与滑铲都相交 → **只能跳**；起跳 0.1s 即越过头顶 |
| `DART_HIGH_LIFT` | 62 | **90** | 高轨盒 [372,408]，顶到头顶以上、滑铲盒底 430 之上净空 22px 恒安全 → **只能滑铲钻过** |
| `DART_WAVE_MIN` | 5 | **3** | 一波 3~5 枚成簇来袭，不铺开 |
| `DART_WAVE_MAX` | 8 | **5** | 同上 |
| `DART_GAP_T_MIN` | 0.42 | **0.55** | 枚间距时间窗，反应时间多约 30%，跳完一枚有缓冲 |
| `DART_GAP_T_MAX` | 0.54 | **0.70** | 同上 |
| `DART_FIRST_LEAD` | 300 | **360** | 首枚入屏预警距离 ≥ 2×REACT_T |

未改：`DART_W=34`、`DART_SPEED=380`（恒定不随场景速度变，保肌肉记忆）、`DART_PIT_LAND_GAP=150`、`DART_WAVE_TAIL_GAP=400`、`DMG_DART=DMG_SPIKE`。

## 2. 关键设计决策（为什么）

1. **"高轨必须滑铲"改为几何硬保证，不再依赖节奏。**
   旧设计靠"滞空 0.708s > 枚间隔 0.54s"让连跳必中——用户实测后认为高低都像能跳，依据太软。
   新设计：高轨 [372,408] 顶在头顶以上，起跳上升段 0.117s 内必撞、下落段再扫回来，几何上就跳不过。
   测试用 aabb 锁死四组关系，防后人改盒子破环躲法：
   - 低轨盒子 ∩ 站立盒 = 相交（站着也中）
   - 低轨盒子 ∩ 滑铲盒 = 相交（滑着也中）→ 低轨只能跳
   - 高轨盒子 ∩ 站立盒 = 相交（站着必中）
   - 高轨盒子 ∩ 滑铲盒 = **不相交**（净空 22px 恒安全）→ 高轨只能滑铲

2. **枚间距放宽是为了"躲避动作成立"，不是更简单。**
   滞空 0.708s、间距 0.55-0.70s：跳完一枚落地后还有约 0.15s 缓冲，不紧逼；加上 `HIT_INVULN_T=1.0 > 0.70s`，连吃两枚之间天然有喘息。

3. **每波 3~5 枚**：一波是一个危险单位（成簇），5~8 枚铺太开会让"潮"读不出来。

## 3. 渲染改动（src/render/entities.js `drawDart`）

- 刃尖半径 `ob.w/2` → `ob.w/2 + 3`（17 → 20）：视觉略大于碰撞盒，刀刃感醒目。判定仍按 34×36 盒，视觉偏大、判定偏严 → 对"看着会擦到其实没擦到"的仁慈方向反了，**玩家反而觉得判定准**（近身飞镖，宁可视觉大一点）。
- 依旧绕质心自转 `rotate(G.gameTime * 14)`，自转仅表现不影响判定。

## 4. 测试改动（tests/dart-wave.test.js）

- 仅改测试描述名：`5-8 darts` → `3-5 darts`。
- 断言语义全部从常量推导（`DART_WAVE_MIN/MAX`、`DART_LOW/HIGH_LIFT`、`DART_GAP_T_MIN/MAX`、`DART_FIRST_LEAD`），新值自动适配，无需改断言数字。

## 5. 验证状态

- 测试：`node --test tests/*.test.js` → **30/30 全绿**（含 dart-wave 4 项、hp-system 飞镖 2 项、continuous-slide 序列）。
- 构建：`npm run build` 通过（31.24 kB gzip 10.95 kB）。
- 浏览器实测（headless + window.G 驱动）：生成 4 枚、双轨 y=372/412、间距 448-505px ∈ [0.55,0.70)×(pace+380)、波尾 `nextSpawnX` 正确推出；canvas 像素采样确认**高低两轨都在新高度绘制**（高轨带 y378-402、低轨带 y418-442 均扫到墨色，采样区 x450-900 避开忍者本体）。

## 6. 未动、且必须守的设计规则（先前既定）

- **飞镖潮独占区段**：EVENT_TPL 的 idx17/21 两个槽位，潮前潮后 coins_flat 平静段，**绝不与其他障碍家族穿插**。
- 坑避让：逐枚 `segAt(cursor)` 检查，落在坑内右移到坑尾 +150（防"低轨逼跳 × 坑跳"叠加）。
- 波尾隔离：波结束后推 `G.nextSpawnX = max(..., 波尾cursor + 400)`，后续静态障碍不插进飞镖潮的到达时间窗。
- 飞镖是**普通伤害**（DMG_SPIKE=12）：护盾可挡、忍术可清、血条硬扛；仅深坑坠落即死。

## 7. 可能的下一步（供讨论，当前未做）

- 难度曲线：当前高低轨 50/50 随机混合。若想让"高轨滑铲"训练更平滑，可考虑低轨先密集、随距离提高高轨占比——需要玩家实测反馈后再定。
- 二段跳与高轨的不公平场景：高轨几何上必须滑铲，若玩家恰在高轨到来时处于空中（跳早了），中弹无法避免。这是刻意的（逼玩家读潮、预判），但若实测过难，可考虑把高轨再抬高几 px 让"跳早落地再滑"可行——改的是 `DART_HIGH_LIFT` 一个数，测试自动适配。

# 飞镖波形编排 + 视觉手感（2026-08-24）

> 承接上面的"飞镖重新设计"。这次做两件事：**波形编排**（每波由一个 pattern 决定高低轨，教学锯齿）与**视觉手感**（刀光拖尾 + 入场墨晕 + 受击水墨爆）。
> 一句话：把"每枚独立随机高低"改成"整波一个语义"，再给飞镖上三层表现。

## 1. 玩法层：波形编排（src/generator.js）

- 新增 `DART_PATTERNS`（hop/slide/alt/lead 四个波形）+ 导出 `waveHigh(pattern, i, n)`（第 i 枚是否高轨）+ 导出 `pickDartPattern(m)`（按行进米数选波）。
- `pickDartPattern` 教学锯齿：`< DART_PATTERN_MIX_M(1500m)` 只出纯波 hop/slide；`< DART_PATTERN_HARD_M(4000m)` 加入 alt；之后四种全出。
- `dart_wave` case：`const high = waveHigh(pattern, i, count)` 替换原 `Math.random() < 0.5`；每枚 dart 带 `pattern` 字段（供测试断言整波一致性）。
- 波数/间距/坑避让/首枚预警/波尾隔离逻辑**全部未动**。

## 2. 视觉层

- **刀光拖尾**（[render/entities.js](src/render/entities.js) `drawDart`）：四刃提为局部 `blade(r)`；主体前画 3 个透明残影副本（向后 7/14/21px，alpha 0.19/0.12/0.05，旋转角滞后）。纯表现不碰碰撞盒。
- **入场墨晕**：飞镖刚入屏（屏幕 x 距玩家 > `DART_APPROACH_RANGE`）叠加淡墨扩散圆（alpha 随距离线性衰减），"远淡近实"给预读躲法的时间。
- **受击水墨爆**（[physics.js](src/physics.js) `updateCollisions`）：`ob.kind === 'dart'` 受击改用 `inkBurst(x,y,14,1.2)`（stroke+drop 双形态、旋转），其余静态障碍保持原 `burst`。复用现有 [particles.js:21](src/particles.js#L21)。

## 3. 常量改动（src/constants.js）

| 常量 | 值 | 语义 |
|---|---|---|
| `DART_PATTERN_MIX` | `['hop','slide','alt','lead']` | 波形顺序即难度阶梯 |
| `DART_PATTERN_MIX_M` | 1500 | 教学期：只出纯波 |
| `DART_PATTERN_HARD_M` | 4000 | 越过教学期加入交替，之后含收尾加强 |
| `DART_APPROACH_RANGE` | 340 | 入场墨晕作用范围 px |

高低轨几何常量（`DART_LOW/HIGH_LIFT`）**未动**——躲法语义与 4 条 aabb 锁定保持原样。

## 4. 测试（tests/dart-wave.test.js）

新增 3 项：
1. `waveHigh` 四波形确定性（hop 恒低、slide 恒高、alt 交替、lead 末枚高）
2. `pickDartPattern` 距离加权（教学期只 hop/slide，后期四种皆可）
3. 整波一致性：生成的一波 dart 的 high 序列 === `waveHigh(pattern)`，且 pattern 属于合法集合

现有 4 条 aabb 几何锁定、波数/间距/波尾隔离断言未改。

## 5. 验证状态

- 测试 `node --test tests/*.test.js` → **33/33 全绿**（原 30 + 新增 3）
- 构建 `npm run build` → 通过（31.85 kB）
- 浏览器实测（window.G + 动态 import 驱动）：教学期 750m 出纯 hop 波（4 枚全低轨 y=412）；后期 4020m 采样 12 次四种波形均现（lead×3/slide×5/hop×2/alt×2）；控制台 0 报错。视觉细节请亲自打开 `http://localhost:5173` 长跑确认。

## 6. 未动、且必须守的设计规则（继承）

- 飞镖潮独占区段（EVENT_TPL idx17/21），不与其他障碍家族穿插。
- 高低轨躲法由盒体几何硬保证（低轨只能跳、高轨只能滑铲）。
- 飞镖普通伤害 DMG_SPIKE=12，仅深坑坠落即死。
- 未加新弹道（弧线/滞空/浮动）——那需要重做几何保证与 aabb 锁定，属下一轮；若要做，务必先扩测试再改盒子。
