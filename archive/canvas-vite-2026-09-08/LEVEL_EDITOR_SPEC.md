# 关卡编辑器设计规格书 (Level Editor Specification)

## 一、概述

为《水墨忍者跑酷》游戏开发一个可视化关卡编辑器,用于手动设计和调试关卡段落。

### 核心目标
- 可视化编辑关卡障碍物和收集物位置
- 提供人物参照工具,辅助设计跳跃/滑铲难度
- 导出/导入 JSON 格式的关卡数据
- 支持编辑器内实时测试

---

## 二、编辑器界面布局

### 2.1 整体结构
```
┌─────────────────────────────────────────────────────┐
│ 顶部工具栏: [保存] [加载] [测试] [清空] [网格开关]    │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  左侧    │        中央画布区 (可横向滚动)            │
│  障碍物  │                                          │
│  面板    │   ←─────  关卡内容  ─────→              │
│          │                                          │
│  [尖刺]  │   [可拖动滚动条]                         │
│  [石柱]  │                                          │
│  [垂板]  │                                          │
│  [飞镖组]│                                          │
│  [金币]  │                                          │
│  ...     │                                          │
├──────────┼──────────────────────────────────────────┤
│          │ 底部属性面板: 选中对象的详细属性编辑      │
└──────────┴──────────────────────────────────────────┘
```

### 2.2 画布区规格
- **尺寸**: 高度540px(游戏画面高度),宽度可滚动(段落长度10-20秒对应的像素)
- **背景**: 宣纸底色 + 地面线(y=462)
- **网格**: 可选显示,横向100px/竖向50px对齐辅助线
- **滚动**: 鼠标拖动或滚轮横向滚动画布
- **缩放**: 暂不支持(保持1:1实际像素)

## 三、障碍物库(左侧面板)

### 3.1 静态障碍物
| 类型 | 图标 | 默认尺寸 | 说明 |
|------|------|----------|------|
| spike | 🔺 | 32×16 | 地面尖刺 |
| pillar | ▮ | 36×90 | 石柱 |
| beam | ▌ | 20×150 | 垂板(从天花板垂下) |
| rock | ⬟ | 40×40 | 落石(带预警) |

### 3.2 动态障碍物
| 类型 | 图标 | 说明 |
|------|------|------|
| dart_wave | ➤➤➤ | 飞镖组(手动摆阵) |
| boulder | ⚫ | 滚石 |
| ninja | 🥷 | 持刀忍者 |

### 3.3 收集物
| 类型 | 图标 | 说明 |
|------|------|------|
| coin | 🪙 | 金币 |
| scroll | 📜 | 卷轴 |
| shield | 🛡️ | 护盾 |

### 3.4 拖拽操作
1. 从左侧面板拖动图标到画布
2. 松开鼠标后,障碍物放置到该位置
3. 自动吸附到网格(如果网格开启)

## 四、人物参照工具

### 4.1 功能
- 在画布上显示玩家角色轮廓(半透明)
- 可拖动到任意位置
- 显示碰撞盒边框

### 4.2 操作模式
| 按键 | 效果 | 显示内容 |
|------|------|----------|
| 无操作 | 站立姿态 | 碰撞盒 46×66px |
| ↑ | 跳跃轨迹 | 抛物线弧(虚线),显示单跳/二段跳高度 |
| ↓ | 滑铲姿态 | 碰撞盒 46×32px |

### 4.3 轨迹预览
- **单跳**: 显示 JUMP_V=920 的抛物线,标注最高点
- **二段跳**: 从单跳轨迹某点再跳,显示 JUMP2_V=840 的第二段弧线
- **滑铲**: 显示低姿态碰撞盒,可前移最多72px

### 4.4 显示样式
- 人物轮廓: 半透明墨色 `rgba(43,43,49,0.3)`
- 碰撞盒: 红色虚线边框 `rgba(165,58,46,0.6)`
- 跳跃轨迹: 青色虚线 `rgba(72,146,164,0.5)`

## 五、飞镖组编辑(重点)

### 5.1 编辑流程
1. 从左侧拖动"飞镖组"图标到画布
2. 进入**飞镖编辑模式**:
   - 画布上显示"点击添加飞镖"提示
   - 每次点击放置一枚飞镖
   - 飞镖显示为手里剑图标(34×36px)
3. 完成后点击"确认",飞镖组成为整体

### 5.2 飞镖组属性
- **组起点**: 整组的世界坐标X(最右侧飞镖的位置)
- **飞镖列表**: 每枚飞镖相对组起点的偏移
  ```javascript
  {
    offsetX: -200,  // 相对组起点向左200px
    offsetY: 50     // 离地高度50px
  }
  ```

### 5.3 运行时行为
- 整组以 DART_SPEED=380 px/s 匀速向左飞
- 保持相对队形不变
- 飞出屏幕左缘后回收

### 5.4 可视化提示
- 编辑模式: 显示每枚飞镖的序号(①②③...)
- 完成后: 整组用虚线框包围,显示"飞镖组"标签
- 选中后: 可整体移动,或双击重新编辑

## 六、对齐与辅助功能

### 6.1 自动对齐
| 功能 | 快捷键 | 效果 |
|------|--------|------|
| 水平对齐 | Shift+H | 选中多个对象,纵坐标对齐到第一个 |
| 竖直对齐 | Shift+V | 选中多个对象,横坐标对齐到第一个 |
| 贴地对齐 | Shift+G | 选中对象底部贴地面线(y=462) |
| 网格吸附 | 拖动时自动 | 位置吸附到最近的网格交点 |

### 6.2 多选操作
- 按住 Shift 点击多个对象
- 或框选: 鼠标拖动矩形框选中区域内所有对象
- 多选后可整体移动、对齐、删除

### 6.3 属性编辑
选中对象后,底部面板显示:
- **位置**: X, Y 坐标(可手动输入精确值)
- **类型**: 障碍物种类(不可改)
- **特殊属性**: 
  - 落石: 预警时间
  - 飞镖组: 飞镖数量、队形预览

## 七、数据格式

### 7.1 关卡段落 JSON 结构
```javascript
{
  "id": "segment_bamboo_001",
  "name": "竹林-跳跃教学",
  "length": 3600,  // 段落总长度(像素)
  "obstacles": [
    {
      "kind": "spike",
      "x": 800,   // 世界坐标X
      "y": 462,   // 世界坐标Y(地面)
      "w": 32,
      "h": 16
    },
    {
      "kind": "dart_wave",
      "x": 2000,  // 组起点
      "darts": [
        { "offsetX": 0, "offsetY": 50 },
        { "offsetX": -300, "offsetY": 90 },
        { "offsetX": -600, "offsetY": 50 }
      ]
    }
  ],
  "collectibles": [
    {
      "type": "coin",
      "x": 1200,
      "y": 380,
      "r": 14
    }
  ]
}
```

### 7.2 导出/导入
- **保存**: 点击"保存"按钮,下载 JSON 文件
- **加载**: 点击"加载"按钮,选择 JSON 文件导入
- **格式校验**: 导入时检查必需字段,错误提示

## 八、测试功能

### 8.1 测试模式
点击"测试"按钮后:
1. 编辑器隐藏,切换到游戏画面
2. 玩家从段落起点开始奔跑
3. 只加载当前编辑的这一段关卡
4. 按 ESC 或死亡后返回编辑器

### 8.2 测试参数
- 速度: 使用当前速度曲线(根据段落长度对应的米数)
- 角色: 完整跳跃/滑铲/碰撞逻辑
- HUD: 显示血条、距离、FPS

## 九、技术实现

### 9.1 技术栈
- **框架**: Vanilla JS (保持与游戏一致)
- **渲染**: Canvas 2D
- **文件**: 独立 HTML 页面 `editor.html`
- **样式**: 复用游戏的水墨画风

### 9.2 核心模块
```
editor/
├── editor.html         # 编辑器入口
├── editor.js           # 主逻辑
├── canvas-editor.js    # 画布渲染与交互
├── obstacle-panel.js   # 左侧面板
├── player-tool.js      # 人物参照工具
├── dart-editor.js      # 飞镖组编辑器
├── io.js               # JSON导出/导入
└── test-runner.js      # 测试模式启动器
```

### 9.3 状态管理
```javascript
const EditorState = {
  mode: 'select',  // select | place | dart_edit
  selectedObjects: [],
  currentSegment: { obstacles: [], collectibles: [] },
  camera: { x: 0, scrollSpeed: 20 },
  gridEnabled: true,
  playerTool: { x: 270, y: 462, pose: 'stand' }
};
```
