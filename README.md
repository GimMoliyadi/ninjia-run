# 水墨忍者 · Godot 重制版

这是当前唯一的运行版本，使用 Godot 4.7 制作。旧的 Canvas/Vite 实现已完整移动到 `archive/canvas-vite-2026-09-08/`，不参与 Godot 项目的导入、运行或维护。

在 Godot 中打开本目录的 `project.godot`，点击右上角的运行项目按钮或按 `F5` 即可开始。

## 当前正式路线：完整地图循环

F5 默认路线保留完整的飞镖阵、跳跃图、绳索图、平台飞镖图和忍者阵，每圈各出现一次。出场按学习层次推进：跳跃与飞镖在前，绳索承接换线，平台与忍者作为后半段综合；同层仍按种子换序。每圈仍为13段，尾段使用跳铲、绳索切换和综合挑战，不再退回单个障碍教学。SAFE、REST、FINISH均为720px短转场，保留金币和完整落地空间。

人物跑姿、高清显示、残影和移动物理保持不变。本阶段按要求不运行自动测试，关卡体验由用户亲自试玩确认。

### 地图节奏改版

这一版不再增加障碍种类，而是调整已有内容的起承转合：

- 飞镖保持43枚和八波，用跨波接拍、挑高回折和横排收束串成连续动作，削去重复尾白，不提速、不压预警。
- 平台从40台精简为31台，仍有八波；从三台识招、三四台短连段，推进到五台回旋、六台呼应，不再八波全是同样长度。
- 绳索把重复长镖列改为同侧短串和上下接力，保留单侧清晰通路，高潮后用单镖短答收势。
- 跳跃先短刺、稍宽刺、落地连跳、短长变化，再引入刃轮穿梁；不再打乱教学顺序。忍者段削去等待，用高低两轮交锋收尾。
- 转场从1200px缩到720px，减少开局和回环连续空跑；不是删掉五类地图。

以上是设计与资源实现，未进行引擎运行、自动测试或人工手感验收。

### 金币跳跃引导

越刺与跨台金币改为按当前物理步采样跳跃轨迹，不再使用固定正弦拱线。采样读取人物跳速、上升/下降重力及空中动量衰减；高低台按真实落台高度截取，需要二段跳的跨度使用顶点补跳参考。金币对齐身体可收集区域，台面直线与起跳、落台位置衔接，原五个手工段的10组跳跃金币也复用同一计算。

这些是按预期起跳方式摆放的静态引导，不会追随玩家任意急降或不同二跳时机移动。恢复段、热身和绳索低压力金币仍按跑动/贴绳收集。本阶段未运行自动测试或试玩。

### 障碍编排升级

- 倒挂长柱改为短悬梁：吊链只是装饰，实体碰撞与梁身一致；可以看清从下方穿过的空间。
- 跳跃图加入「刃轮入阵」与「悬刃读招」：迎面刃轮需要起跳，悬落刃有可见预告并保留低身通道，两者均可被现有技能破坏。
- 碎台先在有承接地面的地方出现，再进入高低断桥；台面预先有碎裂标记，踩上后裂纹展开，随后失去承重并散落。
- 平台飞镖改为坑中镖、台尾镖交替，不再每座平台都重复跳坑后滑铲；忍者三人阵增加真实的台上守位。
- 飞镖增加挑高、折返与高低换线形状，保留原低位接触坐标和间隔；镜头增加前方视野，不缩小人物。

以上内容已接入默认五类完整地图，而非仅放在测试场景。当前只做实现与静态自查，未声明已通过引擎验证或手感试玩。

### 保留的短动作组合资源

以下三种短组合仍保留为练习资源，不再占用默认正式路线：

- **越刺 · 压低 · 再起跳**：跳越地刺，落地滑铲低梁，再次跳铲切换。
- **低身 · 登台 · 回落**：滑铲后起跳落台，回地面再滑铲，再越刺与压低。
- **越刺 · 低梁镖 · 再起跳**：低梁与迎面飞镖共用一个低身窗口，其余继续跳铲切换。

组合长度2000～2080px；400～620px/s边界为3.23～5.20秒。三种子正式角色60Hz无技能实跑：每组合3.68～3.87秒，短喘息1.20～1.27秒，全部无伤。固定 `route_seed` 可复现，重开与暂停逻辑不变；未完成人工手感试玩。

## 完整飞镖地图：逐风 · 飞镖阵

独立练习使用 `Dart_Map_A`。地图长 **8,035 px**，基础跑速约 **20.1 秒**；持续 620 px/s 时约 **13.0 秒**。包含三个 Section、八个 `Dart_Seg*` 段、共 **43 枚飞镖**。飞镖按「动作句」编排：后一枚出现在前一枚所引发轨迹上，不再使用整面竖墙。

飞镖高度只有四层，全部从一段跳高度 `H1 = 184.5` 等比推出：**LOW 46.1**（0.25 H1）、**MID 92.2**（0.50 H1）、**HIGH 143.9**（0.78 H1）、**TOP 175.2**（0.95 H1），另有一条滑铲专用线 **SLIDE 66**。整条飞镖潮的垂直跨度收在 175 px 以内，玩家一眼能看出这条线在上升还是在下降。

按「站立会不会中招」分两类：`h ≥ 站立身高 + 飞镖半径 = 77` 是 **SAFE**（站着就能过），`h < 77` 是 **ACT**（必须在那一刻滑铲中、或脚底离地 57 px 以上）。所以 LOW 与 SLIDE 是 ACT，MID / HIGH / TOP 是 SAFE —— 高度层主要用来**画线**，真正要求动作的是 LOW 与 SLIDE。

### 衔接规则：间隔 / 高低衔接 / 连续组合

本轮只调整**间距**与**组合顺序**，没有增删任何 Pattern，也没有改角色物理、飞镖碰撞或随机化。规则落在「一个滑铲能盖住多少地面」这个量上：

- 滑铲期间玩家实际速度是 `SLIDE_BURST_SPEED = 620`，不是跑速 400。所以一个滑铲覆盖 `0.58 × 620 = **359.6 px**`，不是 `0.58 × 400 = 232 px`。
- 飞镖是**边缘擦到边缘**就命中（`dart.gd` 用 `swept_shape`），所以相遇点在 X 的飞镖实际占住 `[X - 34, X + 34]`，`CONTACT_PAD = 11 + 23 = 34 px`。

由此得到两个合法带，以及中间必须避开的死区：

| 带 | 判据 | 含义 |
|---|---|---|
| **CONTINUOUS** | ≤ 268 px | 一个滑铲同时盖住整簇 —— 上一个动作的轨迹直接把玩家送进下一个 Pattern |
| **CLEAN** | ≥ 384 px | 玩家完整落地、重新判断、再做下一个动作（也满足单跳滞空 282 + 起跳预备 80 = 362 px） |
| 死区 | 268～384 px | 既接不上上一个动作，又来不及从容重来 —— 落进这里的接缝必须改间距或改顺序 |

这三条同时被三层验证覆盖：`dart_wave_layout.gd` 逐波检查、`map_module_chunk.gd` 全图体检（`act_report`）、`dart_map_module_regression.gd` 断言。当前全图 **43 枚飞镖 / 24 枚 ACT / 0 处问题 / 0 处死区**。

地图入口：`patterns/library/Dart_Map_A.tres`；三段编排：`Dart_Map_A_Section1/2/3.tres`；八段数据：`Dart_Seg1_Entry.tres` 至 `Dart_Seg8_Climax.tres`。F1 可查看当前 Section 与 Wave。

验证与截图见 [飞镖地图实跑记录](tests/DART_MAP_VALIDATION.md)。

## 操作

- `Space` / `↑`：跳跃与二段跳
- `S` / `↓`：地面滑铲；空中第一次按下立即急降，第二次预约落地滑铲；绳上按下翻到绳下
- 绳上 `Space`：脱离绳索并上跳；绳下 `Space`：翻回绳上
- `J`：挥刀，前方近距离斩击
- `Shift` / `K`：满查克拉释放巨型螺旋丸，向前飞行并穿透可破坏目标
- `Q`：生成三个环绕火球，短暂环绕后依次追踪前方目标
- `P` / `Esc`：暂停；`R`：重新开始

顶部技能按钮也可点击，显示就绪或剩余冷却。满血隐藏角色血条，受伤立即显示，低血量期间持续显示，恢复满血隐藏。受伤无敌时间为 0.7 秒；死亡和重开会正确处理血量、技能与暂停状态。

跳跃后快速连按两次下键，可在落地当帧接滑铲。只按一次或一直按住只会急降；仍有二段跳时按跳跃可取消急降和滑铲预约。急降起始向下速度为 1200 像素/秒，经过正常物理碰撞落地，不瞬移；接绳、死亡和重开会清除预约。`tests/godot/fast_fall_regression.gd` 覆盖上述空中输入和落地衔接。

### 战斗参数

| 技能 | 冷却 | 行为 |
|---|---|---|
| 刀 | 0.4 秒 | 前方 94 像素、纵向偏差 55 像素内斩击；每个目标只结算一次 |
| 螺旋丸 | 6 秒，消耗 100 查克拉 | 半径 58 像素、速度 950 像素/秒，最多存在 4 秒，穿透可破坏物 |
| 三炎追踪 | 8 秒 | 恰好 3 个火球，环绕半径 62 像素，依次发射，650 像素内索敌；命中爆炸半径 42 像素 |

查克拉初始满值，每秒恢复 20，金币也补充查克拉。火球尽量分配不同目标；无目标时环绕等待，4 秒后消失，飞出后丢失目标会重新索敌，无目标直飞最多 0.65 秒。刀、火球和螺旋丸均可破坏竹刺、飞镖，横梁、地面和绳索不可破坏。当前没有独立敌人系统，索敌对象是这些可破坏障碍。`player.heal(amount)` 支持回血状态更新，本次没有增加新的治疗道具。

战斗由 `components/player_combat.gd` 编排，`ability_projectile.gd` 管理飞行、追踪、命中与回收，`combat_target.gd` 管理可破坏目标判定。`visuals/health_bar.gd` 不继承角色身体的翻转与受伤透明度。轨迹、命中特效使用程序化绘制，没有新增贴图或第三方依赖。

切片通过 Entry/Exit 标记的全局位置对齐。绳索跨越深坑，接近出口时自动翻回绳上衔接平地。绳下使用倒挂跑动：程序化剪影以绳线为轴镜像，脚底贴绳，碰撞盒位于绳下；翻回绳上恢复正立。绳索段障碍以 Rope 为父节点，根部与碰撞盒底边均对齐绳线。

### 手工修改

1. 在 Godot 文件系统中双击表中的场景，切换中央的 2D 视图。
2. 在左侧选择 Spike、SlideBeam 或 Coin 节点，拖动，或修改右侧 Transform → Position。
3. 地面 Spike 的 Y 保持 460；SlideBeam 的 Y 保持 0；Rope 子节点下的 Spike 的 Y 保持 0。只改 X 最容易保持贴地/贴绳。进阶绳索的 SpikeB/SpikeD 使用 Scale Y=-1 朝向绳下，保持这个缩放值。
4. Entry/Exit 和地面长度先不改。Ctrl+S 保存，F5 从热身段开始试玩；运行中 R 重来。

## 程序化角色视觉

角色没有 Sprite2D 或 PNG 依赖，按 F5 即可运行。碰撞与状态由 player.gd 管理；视觉模块只读取状态、速度并监听信号，不写入角色物理。

```text
TestWorld
├─ Player (player.gd)
│  ├─ BodyCollision / RopeDetector
│  └─ PlayerVisual (visuals/player_visual.gd)
│     ├─ Orientation — 以绳线为轴倒挂，独立于挤压缩放
│     │  └─ Body (visuals/ninja_body.gd) — 原生圆形、多边形与肢体曲线
│     │     └─ Neck
│     │        └─ Scarf (visuals/scarf.gd) — 世界坐标历史追踪青金飘带
│     ├─ GhostSpawner (visuals/ghost_spawner.gd) — 无碰撞、无行为的姿态副本
│     └─ RunDust (CPUParticles2D) — 仅地面跑动发射
└─ DynamicCamera (dynamic_camera.gd) — target 指向 Player
```

- player.gd 发出 state_changed、jumped、landed、damaged、run_reset；game.gd 不处理绘制或动效。
- 起跳 0.08 秒拉伸至 (0.7, 1.35)，落地 0.08 秒挤压至 (1.3, 0.7)，随后 0.16 秒回弹；滑铲直接使用贴地前倾姿态。
- 飘带 20 个点，采样真实颈部全局历史坐标，无正弦波或刚体摆动。相邻点距离固定 7 像素，总长 133 像素，宽度从 5 渐变至 1 像素，颜色为青金渐变。水平运动保持平直，升降与滑铲通过历史高度产生自然拖尾；向后风力避免翻转时打结，重开或瞬移清空历史。
- 水平绝对速度超过 RUN_SPEED × 1.1（440 px/s）时，每 0.04 秒生成青/金姿态残影，不依赖滑铲状态；空中超速同样发射。保留世界位置，0.25 秒从 0.6 淡出并释放。重开清空残影。
- 镜头平滑追踪玩家前方 150 像素的目标位置，保持基准 Y=380；根据速度在 1.0～0.85 间缩放。落地、受击通过噪声创伤震动叠加 offset，重开清零。
- 外观是纯程序化剪影，无精绘贴图；动作风格和震动强度可根据试玩反馈继续调整。

视觉测试：tests/godot/player_visual_regression.gd；镜头测试：tests/godot/camera_lock_regression.gd（已改为动态镜头契约）。运行时带 --headless --fixed-fps 60。

## 滑铲跳动量

水平速度统一计算为 run_speed + boost_speed，默认基础跑速 400 px/s；滑铲将动量池设为 220 px/s，同一物理帧达到 620 px/s。滑铲期间保持动量，地面跑动及非翻转绳索以 600 px/s² 衰减，空中以 60 px/s² 衰减。接绳和起跳帧完整保留动量，二段跳也不覆盖水平速度。镜头速度区间为 400～620。

绳上按 S / ↓ 翻到绳下，绳下按 Space / ↑ 翻回绳上；绳上按 Space / ↑ 跳离。过渡时间 0.18 秒，期间冻结动量衰减。碰撞盒立即切换到目标侧，视觉通过绕水平绳轴的侧视投影过渡：身体高度收缩到侧面再展开倒立，横向宽度不变，不再在屏幕平面转半圈。飞镖连续碰撞检查忽略上下换侧的垂直瞬移，但保留目标侧的真实受击判定，不提供翻转无敌。

`rope_flip_projection_regression.gd` 验证上下双向翻转、固定横向宽度、绳线支点、换侧不扫过原侧飞镖，以及目标侧碰撞仍会扣血；无头和真实渲染运行均通过。

按 S / ↓ 后，在 0.58 秒滑铲期间按 Space / ↑ 即可滑铲跳。60 Hz、同高度起落且不中途松开跳跃的实测：普通跳约 233 px，滑铲跳约 352 px（约 1.51 倍）。这是当前物理参数下的测量值，不是任意平台高度下的保证距离。

新增测试：boost_pool_regression.gd（差异衰减、接绳预输入、连续翻转冻结、停止后恢复、离绳跳和重置），slide_momentum_regression.gd（完整继承、跨度、落地恢复、二段跳），scarf_history_regression.gd（30/60/120 FPS、双向移动、360° 翻转与历史回收）。既有视觉测试覆盖空中超速残影持续发射和速度回落后清理。
