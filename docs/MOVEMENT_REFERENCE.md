# 基础移动视频校准

参考：桌面 `忍3.mp4`（960×432，30 fps）与 `codex开发.mp4`（966×636，含编辑器边框）。2026-09-14 对照关键片段的连续帧。以下是视频估算与本项目的近似实现，不是原作内部参数。

## 观察依据

| 视频时间 | 可见现象 | 实现判断 |
| --- | --- | --- |
| 忍3 13–20 秒 | 右侧点按后上升；若随后点按左侧，会提前急坠，随后可再次起跳 | 区分普通跳跃与主动快落，不能把急坠轨迹当作自然重力 |
| 忍3 37–39.3 秒 | 绳上点按左侧后翻到绳下；右侧点按后回到绳上继续跑 | 上下跑道是附着状态切换；翻回上方本身不消耗空中跳跃 |
| 忍3 41.1–41.8 秒 | 右侧点按后立即上升，约 0.3 秒到顶；下降时再点按右侧，角色重新上升并翻滚 | 起跳不等动画；二段跳覆盖垂直速度，不叠加下落速度，也不等翻滚结束才移动 |
| codex开发 38–41 秒 | 角色与地面的相对跳跃幅度较小，镜头也随角色上下移动 | 比较相对地面高度，不能只用角色在屏幕上的纵坐标 |

参考单跳幅度按画面高度折算到本项目 540 像素视口，估计约 170–190 像素；姿势变化、镜头和 30 fps 采样均会带来误差。跑速缺少共同世界尺度，保留现有 400 px/s，避免把滑铲加速或镜头移动当作普通跑速。后续如需精确校准，需同一比例下的静态地标与无额外操作的单跳样本。

## 参数与行为

| 项目 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 普通自动跑速（px/s） | 400 | 400 |
| 一段跳速度（px/s，向上为负） | -820 | -1120 |
| 二段跳速度（px/s） | -790 | -1080 |
| 上升重力（px/s²） | 2400 | 3400 |
| 自然下落重力（px/s²） | 2200 | 2600 |
| 60 Hz 实测一段跳高度 | 133.41 px | 175.30 px |
| 60 Hz 实测二段跳独立上升高度 | 123.50 px | 162.56 px |
| 60 Hz 实测单跳滞空 | 0.683 s | 0.700 s |

保留轻点与长按等高、固定二段起跳速度及最多两跳。修复落地缓冲起跳后，上一帧的地面标记导致下一次快速点按仍被算作一段跳的问题。翻面期间暂停输入缓冲计时，保留下一次点按，翻完即可接跳。绳下的下键不向上翻，跳键先回上面，随后再次点按才起跳。

## 验证

使用 Godot 4.7.2，`--headless --path . --fixed-fps 60 --script tests/godot/<name>.gd`。

- `jump_control_regression`：高度、轻点/长按、二段跳、碰撞盒恢复、土狼时间、落地缓冲、快速连按、禁止第三跳和长按自动连跳。
- `rope_regression`：上下跑道、下方重复下键、快速上翻接跳、脱绳和出口。
- `player_jump_regression`、`rope_flip_projection_regression`、`slide_momentum_regression`：基础起跳、翻面投影与碰撞、横向动量。
- `jump_course_regression`、`jump_map_module_check`、`jump_map_playtest`：五条跳跃路线与完整跳跃地图。

自动测试验证运动与碰撞行为；不能替代实际操作时对手感的判断。
